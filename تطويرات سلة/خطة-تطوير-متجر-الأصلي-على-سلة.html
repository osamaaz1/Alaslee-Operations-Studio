ترتيب الصفحة الرئيسية

  1. شريط قيمة واحد: رسالة شحن/أصالة/خدمة مثبتة ومحددة، لا ثلاث رسائل متحركة.

  4. تسوق حسب النية: طبي، شمسي، عدسات، أطفال، قراءة/خدمة.
  5. الأكثر مبيعاً: 8 منتجات ببيانات مكتملة، لا 30 بطاقة.
  6. اختيار المقاس/شكل الوجه: دليل قصير وروابط إلى فلاتر فعلية.
  7. الثقة: الأصالة، الضمان، الإرجاع، فحص/صيانة، توصيل — بصياغة مثبتة فقط.
  8. العلامات: كل شعار يفتح صفحة Brand الصحيحة؛ لا روابط #.
  9. التقييمات والأدلة: مراجعات مشتري موثق + أحدث مقالتين.
  10. Footer امتثال: CR، VAT، منصة الأعمال الصحيحة، تواصل، شحن، إرجاع، خصوصية، شكاوى، وحسابات مؤكدة.

2. Data Validation نموذج الطلب + إعدادات الحقول + التحقق اليدوي اجعل رقم الهاتف إلزامياً وبصيغة رقمية صحيحة، والبريد بصيغة بريد، والـSKU أو رقم الوصفة ضمن حقول مخصصة إذا لزم. استخدم قوائم منسدلة للقيم المغلقة، ونصاً قصيراً للقيم المفتوحة. أضف رسالة خطأ واضحة لكل حقل ناقص أو بصيغة خاطئة. لا تمر أي طلبات ناقصة البيانات الأساسية، والنماذج غير صالحة تُرفض قبل الدفع أو مباشرة بعده حسب السيناريو.
3. بناء الكتالوج المنتجات ← إضافة/تعديل منتج وحّد اسم المنتج: العلامة + الموديل + النوع + اللون + المقاس. أضف SKU ثابتاً، Brand، MPN/GTIN إن توفر، صورة رئيسية واضحة، 3–6 صور إضافية، وصفاً وظيفياً، وسعر التكلفة قبل هامش الربح. ابدأ بأفضل 50 منتجاً ثم عمّم القالب. كل منتج رئيسي يملك حقولاً مكتملة، ولا يوجد منتج بيع حقيقي بدون صورة أو SKU أو وصف قابل للفهم.
